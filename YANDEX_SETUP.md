# Настройка Яндекса для MyCamDesk

Последнее обновление: 2026-07-13.

## Что уже настроено в коде

- Боевой счетчик Яндекс Метрики: `110404557`.
- Метрика подключается только на `mycamdesk.com`, чтобы тестовый `dev.mycamdesk.com` не портил статистику.
- Включены `webvisor`, `clickmap`, `accurateTrackBounce`, `trackLinks`.
- Для SPA-переходов Next.js отправляется отдельный pageview через `ym(..., "hit")`.
- Ключевые действия отправляют цели через `ym(..., "reachGoal")`.
- `robots.txt` на production открыт для публичных страниц, но закрывает `/admin`, `/cabinet`, `/auth`, `/api`.
- `robots.txt` на dev/localhost закрывает весь сайт от индексации.
- `sitemap.xml` доступен по `https://mycamdesk.com/sitemap.xml`.
- IndexNow key-файл: `https://mycamdesk.com/wejournal-indexnow-key-2026.txt`.
- При создании, редактировании, продлении, скрытии и удалении публичного контента сайт уведомляет Яндекс через IndexNow.

## Цели в Яндекс Метрике

В Метрике нужно создать цели типа `JavaScript-событие` с такими идентификаторами:

- `article_publish` — опубликована статья.
- `product_publish` — опубликован товар.
- `vacancy_publish` — опубликована вакансия.
- `service_publish` — опубликована услуга.
- `resume_publish` — опубликовано резюме.
- `match_profile_publish` — опубликована анкета модель-оператор.
- `resume_invite_sent` — студия отправила предложение по резюме.
- `contact_reveal` — пользователь нажал кнопку просмотра контакта.

Цель `contact_reveal` получает параметр `target_type`: `PRODUCT`, `LISTING`, `RESUME` или `MATCH_PROFILE`. Контактные данные в Метрику не отправляются.

## Настройки счетчика Метрики

Проверить в интерфейсе Метрики:

1. Адрес сайта: `https://mycamdesk.com`.
2. Вебвизор включен.
3. Карта кликов включена.
4. Точный показатель отказов включен.
5. Отслеживание исходящих ссылок включено.
6. Домен `dev.mycamdesk.com` не используется в боевом счетчике.
7. Фильтры: исключить свои IP и внутренние проверки, если есть постоянные IP.
8. Не отправлять персональные данные в цели, параметры и заголовки страниц.

## Яндекс Вебмастер

Проверить в Вебмастере:

1. Добавлен именно `https://mycamdesk.com`, без dev-домена.
2. Права подтверждены через meta-тег `yandex-verification`.
3. В разделе Sitemap добавлен `https://mycamdesk.com/sitemap.xml`.
4. В анализе `robots.txt` нет запрета на публичные разделы.
5. Метрика 110404557 связана с сайтом в Вебмастере.
6. Включен обход страниц по счетчику Метрики.
7. Проверить URL в инструменте проверки страниц:
   - главная;
   - статья;
   - вакансия;
   - услуга;
   - товар;
   - резюме;
   - анкета модель-оператор;
   - гайд.
8. Для новых важных страниц после публикации проверять статус индексирования через несколько дней.

## Что не делать

- Не подключать боевой счетчик Метрики на `dev.mycamdesk.com`.
- Не добавлять dev-домен в Яндекс Вебмастер.
- Не отправлять в цели email, Telegram, телефоны, имена и другие персональные данные.
- Не отправлять весь исторический sitemap в IndexNow вручную; IndexNow нужен для новых, измененных и удаленных URL.
